# adobe-express-bridge — پل Adobe Express

پلی محلی که به یک ایجنت هوش مصنوعی اجازه می‌دهد سندهای **Adobe Express** را برنامه‌ای کنترل کند — بدون نیاز به API رسمی.

```
ایجنت شما ──POST /enqueue──▶ رله‌ی HTTPS روی localhost:8322 ──GET /poll──▶ پنل افزونه (داخل Express)
ایجنت شما ◀─GET /result/:id─ رله ◀──────────────POST /result──────────── پنل ──apiProxy──▶ سندباکس سند
```

## چرا ساخته شد؟

سرور MCP میزبانی‌شده‌ی ادوبی برای Express، ‏redirect URI شخص ثالث را رد می‌کند؛ پس ایجنت بیرونی از مسیر رسمی وصل نمی‌شود. ولی **افزونه‌های (Add-on) Express** داخل خود محصول با SDK کامل سند اجرا می‌شوند. این پروژه یک افزونه‌ی محلی را به پل تبدیل می‌کند:

1. ایجنت یک فرمان JSON ‏(`ping`، ‏`addText`، ‏`addRect`، ‏`exportPage` و…) به یک رله‌ی HTTPS کوچک و بدون وابستگی روی `localhost:8322` می‌فرستد.
2. **پنل** افزونه (در حال اجرا داخل Express) از رله poll می‌کند، فرمان را از طریق **سندباکس سند** روی سند زنده اجرا می‌کند و نتیجه را برمی‌گرداند.
3. ایجنت نتیجه را می‌خواند — از جمله رندر PNG صفحه که رله در `relay/shots/` ذخیره می‌کند.

کل حلقه محلی است و در عمل (نسخه ۱٫۱) سرتاسری وریفای شده، از جمله رندر فارسی راست‌به‌چپ با فریم‌چک.

## اجزا

| مسیر | چیست |
|---|---|
| `relay/relay.mjs` | رله‌ی HTTPS نود بدون وابستگی: صف فرمان، احراز با توکن، ذخیره‌ی نتیجه، ذخیره‌ی PNG |
| `addon/` | افزونه‌ی Express ساخته‌شده با ‎`@adobe/ccweb-add-on-scripts` |
| `addon/src/index.js` | سمت پنل: poll از رله، مسیریابی فرمان‌ها، ‏`exportPage` با UI SDK |
| `addon/src/sandbox/code.js` | سندباکس: ‏`ping`، ‏`addRect`، ‏`addText`، ‏`listFonts` و دیاگنوستیک‌های `probeText*` |
| `docs/OPERATIONS.md` | پروتکل و یادداشت‌های دیپلو (انگلیسی) |

## راه‌اندازی خلاصه

1. در `addon/src/manifest.json` مقدار `YOUR_ADDON_TEST_ID` را با `testId` افزونه‌ی ثبت‌شده‌ی خودتان در Adobe Developer Console جایگزین کنید.
2. توکن پل بسازید: `openssl rand -hex 24 > relay/token.txt`
3. گواهی TLS برای `localhost` بسازید (SAN باید `localhost` باشد، نه `127.0.0.1`) — دستور کامل در README انگلیسی.
4. رله را اجرا کنید: `node relay/relay.mjs` و یک بار `https://localhost:8322/health` را در مرورگر باز و گواهی را قبول کنید.
5. توکن را در کپی کاری پنل جایگزین کنید: ‏`sed "s/__BRIDGE_TOKEN__/$(cat relay/token.txt)/" addon/src/index.js` — توکن واقعی را هرگز کامیت نکنید.
6. افزونه را اجرا کنید: `cd addon && npm install && npm run start` و در Express از «Test your local add-on» پنل Express Bridge را باز کنید.

## یافته‌های فارسی / راست‌به‌چپ (بخش سختِ کار)

این‌ها با پروب زنده و فریم‌چک رندر به دست آمده‌اند و برای **هر متن عربی‌خط** (فارسی، عربی، اردو) در این بیلد Express صدق می‌کنند:

- **استایل فقط با `fullContent.applyCharacterStyles` و با ترتیب (استایل، بازه):** شکل درست فراخوانی `applyCharacterStyles(styles, {start, length})` است؛ ترتیب برعکسِ به‌ظاهر مستندی از طرف ران‌تایم رد می‌شود. `color` یک شیء RGBA ساده است.
- **روی متن فارسی/RTL هرگز `node.layout` (حالت AutoHeight) را ست نکنید:** ست‌کردن `layout = {type: 2}` روی نود عربی‌خط خطای `Text native error: non-WebAssembly error` می‌دهد (متن لاتین قبول می‌کند) و می‌تواند سندباکس را برای عملیات بعدی قفل کند. به‌جای آن، پل متن را **خودش پیش‌پیچ (pre-wrap)** می‌کند: شکست خط روی مرز کلمه با `maxChars = floor(width / (size × 0.52))` و فقط روی فاصله‌ها، تا کلمات نیم‌فاصله‌دار (ZWNJ) سالم بمانند.
- **`translation` نود متن، مرکز آن است، نه گوشه‌ی بالا-چپ:** وقتی `width` داده شود، ‏`addText` مختصات `x/y` را گوشه‌ی بالا-چپ بلوک می‌گیرد و به‌اندازه‌ی `(width/2, wrappedLines × size × 1.5 / 2)` شیفت می‌دهد.
- **`listFonts` در این نسخه‌ی SDK خراب است:** شمارش فونت‌ها نتیجه‌ی قابل‌استفاده نمی‌دهد؛ فونت را با نام خانواده (`fonts.fromFamilyAndStyle`) بگیرید و خروجی را بصری وریفای کنید.

## محدودیت‌ها

- گردش‌کار افزونه‌ی دولوپری/تستی است، نه افزونه‌ی منتشرشده؛ Express باید باز و پنل لودشده باشد.
- صف رله در حافظه است؛ ری‌استارت رله فرمان‌های صف را می‌اندازد.
- پنل بیلد خودش را کش می‌کند؛ بعد از تغییر کد، پنل را در Express دوباره لانچ کنید.
- روی macOS وریفای شده؛ رله نود خالص است و هرجا باید کار کند.

## امنیت

رله فقط روی `127.0.0.1` گوش می‌دهد و همه‌ی فراخوانی‌ها (جز `/health`) توکن می‌خواهند. هرگز آن را روی اینترنت باز نکنید. `token.txt` و `cert.pem`/`key.pem` در گیت‌ایگنورند؛ مال خودتان را بسازید.
